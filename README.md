# DNA Sequence & GC Content Analyzer

A lightweight Python script designed to parse raw DNA sequences, compute nucleotide base counts, determine overall GC content, and categorize biological sequence stability.

## Features
- **String Sanitization:** Automatically strips whitespace and standardizes sequence input to uppercase.
- **Nucleotide Composition:** Calculates absolute counts and exact percentages for G and C bases.
- **Stability Classification:** Evaluates GC percentage against standard biological thermal stability thresholds.

## How to Run
```bash
python DNA_Sequence_Analyzer.py
